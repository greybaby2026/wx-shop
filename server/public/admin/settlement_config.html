门店结算配置

结算基数：小程序实际成交价 × 比例 —— 归属门店（付款方）向交货门店（收款方）结算

全局设置

切换到「商品协商价」需商品规格已维护供货价/成本价，否则金额会为 0 并标记「待复核」。

%

门店未单独设置比例时使用该值。
比例含义：归属门店向交货门店结算的比率（等价于加盟商进货成本率）。
例：成交价 169 元、比例 65% → 归属门店付给交货门店 109.85 元，归属门店留存 59.15 元。

门店独立比例

填 0 或留空表示跟随全局比例；不同加盟商条件不同时可单独设置。

计算口径说明

单件成交价  = (该行实付商品金额 total_pay_price − 运费 express_price) ÷ 数量
单件结算单价 = 单件成交价 × 所用比例
行结算额    = 单件结算单价 × 数量
账单金额    = Σ 行结算额

比例取值优先级：门店独立比例（>0） → 全局比例
生效前提：订单为「门店自提」且 归属门店 ≠ 交货门店（同店不产生结算）
异常兜底：比例未配置 / 成交价为 0 → 金额为 0，并标记「待复核」需人工介入
