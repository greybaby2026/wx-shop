🔒 认证方式

请求头 (Header)

参数 必填 说明
app-key 是 应用标识
timestamp 是 当前时间戳（秒）
sign 是 签名（见下方算法）
nonce 否 随机字符串（防重放攻击）

签名算法

1. 将请求参数按key升序排序
2. 拼接：appKey + timestamp + 参数字符串 + appSecret
3. MD5加密得到签名

PHP签名示例

$appKey = 'jiangjunshijia_open_2026';
$appSecret = 'Jjsj@OpenApi#Secret!2026';
$timestamp = time();
$params = ['user_id' => 1];
ksort($params);
$paramStr = http_build_query($params);
$sign = md5($appKey . $timestamp . $paramStr . $appSecret);

POST /openapi/user/rechargeCommission 新增

充值佣金列表接口

获取用户的充值分销佣金记录列表。充值佣金是指用户下级充值时，按配置比例即时结算到上级可提现余额的佣金，与购物分销佣金独立计算。

请求参数

参数 必填 类型 说明
user_id是int获佣用户ID
start_time否string开始时间 (Y-m-d)
end_time否string结束时间 (Y-m-d)
page_no否int页码（默认1）
page_size否int每页数量（默认25，最大100）

返回示例

{
    "code": 1,
    "msg": "success",
    "data": {
        "user_info": {
            "user_id": 1,
            "nickname": "获佣用户昵称",
            "user_earnings": 500.00
        },
        "statistics": {
            "total_earnings": 300.00,
            "first_level_earnings": 200.00,
            "second_level_earnings": 100.00,
            "total_count": 15
        },
        "list": [
            {
                "id": 1,
                "sn": "CJ20260501001",
                "recharge_order_sn": "CZ20260501001",
                "level": 1,
                "level_desc": "一级",
                "ratio": 20.00,
                "recharge_amount": 5000.00,
                "earnings": 1000.00,
                "status": 1,
                "status_desc": "已结算",
                "from_user_info": {
                    "id": 5,
                    "nickname": "充值用户昵称",
                    "mobile": "13800138000"
                },
                "settle_time": "2026-05-01 10:00:00",
                "create_time": "2026-05-01 10:00:00"
            }
        ],
        "page": {
            "page_no": 1,
            "page_size": 25,
            "total": 15,
            "pages": 1
        }
    }
}
说明： 充值佣金与购物分销佣金是两套独立体系。充值佣金在用户充值成功后即时结算到上级可提现余额，充值金额等额用于购物但不再参与购物分销佣金计算。佣金层级：一级=充值用户的直接上级，二级=充值用户的间接上级。

📋 订单状态说明

状态值 说明
0待付款
1待发货
2待收货
3已完成（已确认收货）
4已关闭
有效成交订单： 订单状态为3（已完成/已确认收货）的订单

📋 售后状态说明

状态值 说明
1售后中
2售后成功
3售后失败
售后方式 说明
1仅退款
2退货退款
售后类型 说明
1整单退款
2商品售后

📋 充值佣金说明

字段 说明
level佣金层级：1=一级（充值用户的直接上级），2=二级（充值用户的间接上级）
ratio佣金比例（%），后台可配置一级/二级比例
recharge_amount触发佣金的充值金额
earnings实际佣金金额 = 充值金额 × 佣金比例
status佣金状态：1=已结算（充值成功后即时结算）
from_user_info触发佣金的充值用户信息
重要说明：
1. 充值佣金与购物分销佣金是两套独立体系，互不影响。
2. 充值佣金在充值成功后即时结算到上级可提现余额，无需等待。
3. 充值金额等额用于购物消费，但该部分不再参与购物分销佣金计算，避免重复分佣。
4. 佣金比例和单笔上限可在后台「充值规则」中配置。
