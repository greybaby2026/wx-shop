1什么是分销？

分销 = 推荐别人买东西，你拿佣金

把将军世家的商品推荐给朋友，朋友下单购买，你就能获得一笔佣金奖励。就这么简单。

2谁可以成为分销会员？

所有人！

将军世家采用"全员分销"模式，只要你注册了小程序账号，就自动成为分销会员，无需申请、无需审核。

3.2 等级是怎么定的？

等级完全由你在分销团队中的位置决定，不需要消费、不需要申请，系统自动判定：

你的位置等级通俗理解
没有上级 大将军王团队创始人，你是源头
有一级上级 大将军被大将军王直接邀请
有二级上级 将军被大将军邀请

举个例子：

大将军王（张总） ← 没有上级
└── 大将军（小王） ← 被张总邀请
└── 将军（小李） ← 被小王邀请
└── 将军（小赵） ← 被小李邀请
简单记：你上面有几层上级，就决定你是什么等级。越靠近源头，等级越高。
3.3 什么叫"一级佣金"和"二级佣金"？
你（分销员A）
└──小王（B）→ 你的一级下级
└──小李（C）→ 你的二级下级
  • 一级佣金：小王买东西 → 你获得订单金额 20% 的佣金
  • 二级佣金：小李买东西 → 你获得订单金额 5% 的佣金
3.4 等级会变吗？

会自动变。当你绑定了邀请人（填写邀请码或通过分享链接注册），系统会自动根据你在分销树中的位置更新你的等级。

5怎么赚钱？两种佣金

推荐别人在将军世家消费，你能获得佣金。佣金分两种：购物佣金和充值佣金。

5.1 购物佣金

朋友通过你的推荐购买商品，你获得购物佣金。

购物佣金 =（商品实付金额 - 运费）× 佣金比例
举个例子

小王买了一件衬衫，实付300元，运费0元，一级佣金比例20%

你的佣金 = (300 - 0) × 20% = 60元

结算时间：订单完成后立即结算（结算天数0天）

朋友下单付款→ 佣金"待返佣"→ 朋友确认收货→ 订单完成→ 佣金到账

佣金状态：

待返佣
等待结算
已结算
已到账可提现
已失效
退款不发放
5.2 充值佣金

朋友通过你的推荐充值余额，你获得充值佣金。

举个例子

小王充值了500元，一级佣金比例20%

你的佣金 = 500 × 20% = 100元

结算时间：实时到账！朋友充值成功后，佣金立即进入你的可提现余额，不需要等待。

5.3 两种佣金对比

购物佣金

朋友购买商品 一级20% / 二级5% 订单完成后结算 可提现

充值佣金

朋友充值余额 一级20% / 二级5% 实时到账 可提现
5.4 全部商品参与分销

将军世家所有商品均参与分销，你推荐任意商品，朋友下单后都能获得佣金。

5.5 什么情况不产生佣金？
  • 余额支付 — 用账户余额付款的订单不产生分销佣金
  • 非分销商品 — 未参与分销的商品不产生佣金
  • 上级被冻结 — 你的上级被冻结分销资格后不会获得佣金
  • 订单退款 — 订单发生退款时佣金会失效
6你的账户余额说明

你的账户里有两种余额，用途不同：

钱包余额

你自己充值的钱、提现到钱包的钱
不能提现可以购物

可提现余额

你赚的佣金（购物佣金+充值佣金）
可以提现不能购物
简单记：自己充的钱只能花，赚的佣金只能提。
如果你想用佣金购物，可以先提现到"钱包余额"，再用钱包余额付款。

申请提现→ 选择方式→ 填写金额→ 后台审核→ 到账
7.4 注意事项

  • 微信零钱提现需审核，审核通过后自动到账
  • 银行卡/收款码提现需审核，审核通过后需人工转账
  • 提现申请提交后不可撤回
  • 如审核不通过，金额会退回到可提现余额

9常见问题
我推荐了朋友，但没收到佣金，为什么？
可能的原因：
1. 朋友下单时用的是余额支付（余额支付不产生分销佣金）
2. 朋友买的商品没有参与分销
3. 佣金还在"待返佣"状态，等订单完成后才会结算
4. 朋友下单时没有通过你的分享链接/二维码进入
朋友之前通过我分享进入过小程序，后来自己下单，我还能拿到佣金吗？
能。只要朋友首次通过你的分享进入小程序，就会自动绑定为你的一级下级。之后TA无论何时下单，你都能获得佣金。
我可以推荐多少人？
没有上限。你可以推荐任意数量的人，每个人下单你都能获得佣金。
佣金比例会变吗？
佣金比例由后台统一管理，可能会根据运营策略调整。你当前的佣金比例取决于你的分销等级。
我的上级是谁？可以换吗？
你首次绑定邀请人后，上下级关系即确定。一般情况下不可自行更换，如有特殊情况请联系客服。
如果订单退款了，佣金会退回吗？
会。如果订单发生退款，对应的佣金会被标记为"已失效"，不会发放。如果佣金已经结算到账，系统会从你的可提现余额中扣除对应金额。
我的等级是怎么定的？能自己选吗？
不能自己选。等级完全由你在分销团队中的位置决定：没有上级就是大将军王，有一级上级就是大将军，有二级上级就是将军。当你绑定邀请人后，等级会自动更新。
分销员会被冻结吗？
后台管理员有权冻结分销员资格。被冻结后：你不会再获得任何新的佣金；之前已产生的待返佣订单仍会正常结算。如有疑问请联系客服。
