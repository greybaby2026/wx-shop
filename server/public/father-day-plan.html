将军世家 · 父亲节充值抵扣活动方案

版本：v1.0  |  日期：2026-05-19  |  状态：待审核

一、活动概述

项目内容
活动名称父亲节充值抵扣活动
核心玩法用户充值到钱包余额，下单时余额自动抵扣订单金额的N%
分销规则仅充值产生佣金（二级分销），购物订单不再产生佣金
活动期限可后台配置起止时间，到期自动关闭

二、用户操作流程

第一步：充值

用户打开小程序 → 点击"充值" → 选择充值金额 → 微信支付 → 钱包余额到账
  • 充值金额不设最低限制
  • 充值即送等额钱包余额（如充100元，钱包余额+100元）
  • 充值成功后，上级分销员实时获得佣金（比例后台可配置）：
    • 一级上级：充值金额 × 2%（默认）
    • 二级上级：充值金额 × 1%（默认）

第二步：购物

用户选购商品 → 进入结算页 → 系统自动计算抵扣 → 微信支付剩余金额

结算页展示示例

┌──────────────────────────────────┐
│  商品金额：         ¥500.00       │
│  运费：             包邮           │
│  ────────────────────────────    │
│  余额抵扣（40%）：  -¥200.00      │  ← 自动计算
│  ────────────────────────────    │
│  还需支付：         ¥300.00       │  ← 微信支付
│                                  │
│  钱包余额：¥800.00（抵扣后）       │
│                                  │
│  [ 微信支付 ¥300.00 ]            │
└──────────────────────────────────┘

第三步：完成

  • 支付成功 → 订单生成 → 不产生购物佣金
  • 钱包余额自动扣减已抵扣的200元

三、核心业务规则

3.1 抵扣规则

规则说明
抵扣来源用户钱包余额（user_money）
抵扣比例后台可配置，默认40%
适用范围订单商品总金额（不含运费，全部商品包邮）
抵扣上限不超过订单金额的N%，且不超过钱包余额
抵扣公式实际抵扣 = MIN(订单金额 × 抵扣比例%, 钱包余额)
活动期外抵扣开关关闭，全额微信支付，余额仍可用于全额支付

3.2 分销规则

规则说明
购物佣金关闭（后台手动关闭分销开关即可）
充值佣金二级分销，比例后台可配置（默认一级2%、二级1%），实时到账 user_earnings
佣金提现不变，仍从 user_earnings 提现到微信/银行卡

3.3 余额规则

规则说明
充值入口不变，复用现有充值页面
余额用途活动期间：抵扣购物 / 活动期外：全额支付购物
余额提现不可提现
余额退款订单退款时，抵扣部分退回钱包余额

四、后台配置项

新增：活动配置

配置键类型默认值说明
activity_deduct_switchint0充值抵扣开关：0=关闭 1=开启
activity_deduct_ratioint40抵扣比例（百分比），如40表示可抵扣订单金额40%
activity_start_timedatetimenull活动开始时间
activity_end_timedatetimenull活动结束时间
recharge_commission_ratio_1int2充值一级佣金比例（百分比）
recharge_commission_ratio_2int1充值二级佣金比例（百分比）

五、技术改动点

5.1 后端改动

文件改动内容
OrderLogic 下单结算新增：计算抵扣金额 → 扣减 user_money → 生成微信支付金额
PayNotifyLogic::order()支付回调中确认抵扣状态
RefundLogic 退款新增：退款时退回抵扣的余额 + 原路退回微信支付部分
活动配置新增抵扣开关/比例/时间范围的配置项

5.2 前端改动

页面改动
首页增加父亲节活动入口（Banner/弹窗）
结算页显示抵扣明细行 + 剩余支付金额 + 微信支付按钮
充值页添加活动主题装饰
商品详情页可选活动角标

5.3 不动的部分

模块状态
充值流程完全复用
充值佣金读配置比例（不再硬编码），仍实时到账 user_earnings
分销等级完全复用（按分销树深度）
提现系统完全复用（佣金提现）
钱包余额完全复用 user_money
可提现余额完全复用 user_earnings

六、退款处理规则

场景处理方式
全额退款微信支付部分原路退回 + 抵扣部分退回钱包余额
部分退款按抵扣比例拆分：N%退钱包余额，(100-N)%退微信
退款时活动已结束抵扣部分仍退回钱包余额（不改变退款的资金来源性质）

示例：用户购买500元商品（余额抵扣200+微信支付300），退其中100元商品：

  • 100 × 40% = 40元 → 退回钱包余额
  • 100 × 60% = 60元 → 退回微信
